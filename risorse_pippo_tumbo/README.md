# pippo-tumbo-video

Kit di produzione dei video 3D «Pippo e Tumbo»: script Blender, personaggi, oggetti di scena, libreria asset, voci, copioni e regole.

Per usarlo in una chat di Claude: chiedi di aprire questo repository e di leggere `LEGGIMI_CLAUDE.md`.

| Cosa | Dove |
|---|---|
| Istruzioni complete per Claude | `LEGGIMI_CLAUDE.md` |
| Brief su copioni, retention e regia | `MASTER_PROMPT_2.md` |
| Regole della serie e sistema narrativo | `BIBBIA.md` |
| Copioni | `COPIONI.md` |
| Elenco delle funzioni | `API.md` |
| Script Blender, audio e sottotitoli | `scripts/` |
| Libreria asset (scarica da sola modelli, texture e cieli) | `assets/` |
| Voci registrate e tempi delle parole | `audio/` |
| Effetti sonori (CC0) e musica (CC-BY, da citare) | `audio/sfx/`, `audio/musica/`, guida in `audio/LEGGIMI_AUDIO.md` |
| Schede di opzioni con le scelte fatte | `schede/`, `riferimenti/` |
| Modelli di script e comandi | `templates/` |

Non sono qui i video finiti, i file `.blend`, i fotogrammi e le librerie scaricate: si rigenerano dagli script.
